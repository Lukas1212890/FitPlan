# FitPlan

Soukromá offline aplikace pro osobní trénink, regeneraci a později také jídelníček.

## První verze

- workout na celé tělo pro hrazdu, bradla, lavičku a ab wheel
- série, opakování a automatický časovač pauz
- volitelné české hlasové pokyny
- jednoduchá animovaná ukázka pohybu
- ukládání rozpracovaného tréninku pouze do zařízení
- instalovatelná aplikace pro iPhone a počítač

## Spuštění

Projekt vyžaduje Node.js 22 nebo novější.

```bash
pnpm install
pnpm dev
```

## Soukromí

FitPlan v této verzi nepoužívá účet, analytiku ani vzdálenou databázi. Tréninková data zůstávají v prohlížeči uživatele.
